## Un poco sobre mí

Me gusta convertir necesidades en herramientas que funcionen. He realizado proyectos en Python, PHP, Java y .NET, aplicaciones para Android y sitios con WordPress.

También he trabajado con web services, JSON y consumo de APIs, incluyendo integraciones con Rappi y Siesa Enterprise. Me interesa que las aplicaciones se comuniquen y que la información llegue a donde se necesita.

Hoy estoy comenzando con **Go y TypeScript**. Codex y Claude forman parte de mi caja de herramientas para explorar ideas, desarrollar y seguir aprendiendo.
